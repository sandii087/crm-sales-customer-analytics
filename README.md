# CRM Sales & Customer Analytics

An end-to-end data analytics project analyzing CRM, customer, sales, and opportunity data.

## Objectives
- Clean and validate CRM data using Python and Pandas
- Store structured data in MySQL
- Perform business analysis using SQL
- Analyze sales funnel and revenue KPIs
- Build visualizations and dashboards
- Translate findings into business recommendations

## Technology Stack
- Python
- Pandas / NumPy
- MySQL / SQL
- Tableau
- Matplotlib / Seaborn
- Jupyter
- Git / GitHub
